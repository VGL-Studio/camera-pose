# PHIÊN TỰ CHẠY

Mỗi file `RUN-YYYYMMDD-NN.md` là danh sách chạy và báo cáo của một phiên tự chạy, theo [mẫu phiên tự chạy](../templates/run.md) và [quy trình](../auto-run.md).

Các phiên RUN-20261015-01 tới RUN-20261017-03, chạy trong lúc xây dựng dự án mẫu, đã chuyển khỏi nhánh chính ngày 2026-10-18; đọc lại ở commit b24fbf4 (`git show b24fbf4:docs/runs/<tên file>`). Tài liệu quy trình vẫn nhắc tới các mã này làm nguồn của bài học.
